## 👨‍💻 About Me

I'm a Full-Stack Web Developer from Bangladesh who enjoys turning ideas into clean, fast and user-friendly web applications. I work with the React ecosystem on the frontend and Node.js on the backend, and I learn best by building real-world projects. Alongside development, I'm deeply interested in AI and entrepreneurship, and I love exploring how technology can solve everyday business problems.
